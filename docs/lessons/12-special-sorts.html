شبكة ترتيب (Sorting Network)

سلسلة comparators ثابتة: كل واحدة بتاخد سلكين وترجع الأصغر والأكبر. المهم إن التسلسل مش معتمد على البيانات — نفس البوابات لكل المدخلات. عشان كده ينفع يتفضّ في هاردوير أو SIMD.

Batcher's odd-even merge

فكرة عميقة: تقدر تدمج سلسلتين مرتّبتين بشبكة من المقارنات من غير فروع. النسخة غير الريكيرسية بتلف على خطوات p و k وتطبّق compexch على أزواج محسوبة بهندسة ثنائية.

void batcher_sort(Item a[], int N) {  /* N = power of 2 */
    for (int p = 1; p < N; p += p)
        for (int k = p; k > 0; k /= 2)
            for (int j = k % p; j + k < N; j += k + k)
                for (int i = 0; i < k; i++)
                    if ((i+j)/(p+p) == (i+j+k)/(p+p))
                        compexch(a[i+j], a[i+j+k]);
}
مش بديل يوميعلى CPU عادي، Quick/Merge/Heap هيكسبوا. قيمة Batcher تظهر في الدوائر، الـ GPU kernels، وأوراق الـ oblivious algorithms (اللي ما بتسرّبش معلومات بالتفرّع).
