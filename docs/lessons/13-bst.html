من هنا ندخل نصف الكتاب التاني: البحث. جدول الرموز (symbol table) = ضع مفتاح→قيمة، دور، احذف. أبسط تنفيذ مرتّب بالمقارنات: الشجرة الثنائية للبحث.

هدف الدرس: تبني BST، تفهم البحث والإدخال، وتشوف الدوران و root insertion.

العقد

كل عقدة: مفتاح، قيمة، شمال، يمين (وأحيانًا عدّاد N لحجم الشجرة الفرعية). الخاصية: كل اللي في الشمال أصغر، كل اللي في اليمين أكبر.

Item searchR(link h, Key v) {
    if (h == z) return NULLitem;
    if (eq(v, key(h->item))) return h->item;
    if (less(v, key(h->item))) return searchR(h->l, v);
    return searchR(h->r, v);
}
inorder = ترتيبلف شمال، اطبع، لف يمين — والمفاتيح تطلع متصاعدة. عشان كده سادجوك بيسمّيها كمان طريقة ترتيب (tree sort).

الإدخال

دور لحد ما توقع على رابط فاضي، وعلّق عقدة جديدة. النسخة الريكيرسية أنيقة؛ غير الريكيرسية محتاجة تمسك الأب.

الدوران و Root Insertion

rotR و rotL بيغيّروا شكل الشجرة من غير ما يكسروا خاصية الـ BST. Root insertion = أدخل وبعدين دور لحد ما العقدة الجديدة تبقى جذر. مفيد كلبنة للشجر المتوازنة والعشوائية.

الكابوسمدخلات مرتّبة (1,2,3,…). الشجرة بقت قائمة مرتبطة. البحث O(N). الحل في الدرس الجاي: توازن إجباري أو عشوائي.

بحث ناجح في BST متوازنة تقريبًا؟

كل مقارنة بتشيل نص الشجرة تقريبًا لو متوازنة.

إيه اللي بيكسر أداء BST العادي؟

الشكل معتمد على ترتيب الإدخال. مفيش ضمان وحدك.

الدوران (rotation) بيحافظ على إيه؟

الترتيب inorder ثابت؛ الارتفاع والاتجاه بيتغيّروا.

Root insertion بيعمل إيه للعقدة الجديدة؟
