تخيّل عندك شبكة كمبيوترات، وكل شوية حد بيقولك «وصّل الجهاز 3 بالجهاز 8». السؤال اللي بيتكرر: هل 3 و 8 أصلًا في نفس المكوّن؟ لو لأ، وصّلهم. لو أيوه، بلاش نكرّر الشغل.

دي مشكلة التوصيل (connectivity / dynamic equivalence). وأول خوارزمية في الكتاب كلها عنها — مش صدفة: بسيطة، وفيها درس عميق عن إن «الخوارزمية الصح» بتفرق جدًا.

هدف الدرس: تفهم quick-find و quick-union و weighted quick-union و path compression، وتعرف ليه الأخير قرب من السحر.

الفكرة: مصفوفة أسماء (id[])

كل عنصر له «اسم مكوّن». لو id[p] == id[q] يبقى p و q متوصلين. في البداية كل واحد اسمه نفسه: id[i] = i.

1) Quick-find

الـ find رخيص جدًا: مقارنة واحدة. بس الـ union غالي: تلف على كل المصفوفة وتغيّر الاسم. على N عنصر و N عملية، التكلفة ~ N². تموت مع البيانات الكبيرة.

/* Program 1.1 — الفكرة */
if (id[p] == id[q]) continue;          /* already connected */
for (t = id[p], i = 0; i < N; i++)
    if (id[i] == t) id[i] = id[q];     /* rename the whole component */

2) Quick-union

بدل ما id[i] يكون اسم، نخليه أب. المكوّن شجرة، والجذر هو الممثّل. الـ union = اربط جذر بجذر. أرخص… إلا لو الشجرة بقت سلسلة طويلة زي معكرونة، ساعتها الـ find بيمشي الطريق كله.

3) Weighted quick-union

الحل البسيط العبقري: اربط الشجرة الأصغر تحت الأكبر. كده مفيش سلسلة طويلة — الارتفاع ≤ lg N. الدليل في الكتاب (Property 1.3).

if (sz[i] < sz[j]) { id[i] = j; sz[j] += sz[i]; }
else               { id[j] = i; sz[i] += sz[j]; }

4) Path compression (halving)

وإحنا طالعين للجذر، خلّي كل عقدة تشير لجَدّها: id[i] = id[id[i]]. بعد شوية عمليات الشجر بتبقى شبه مسطّحة. التكلفة العملية ≈ ثابتة.

مثال يدويابدأ بـ 0..9. Union(3,4) → 3 تحت 4 (أو العكس، الاتنين size=1). Union(4,9) → الشجرة بقت 3 عقد. Union(8,0). Union(2,3) — 2 يدخل تحت شجرة 3-4-9. لو جيت Union(5,9) و size الشمال أصغر، بيتعلق تحت اليمين. جرّب بنفسك في الأداة فوق.
خلي بالك من الغلطة ديتنسى الـ weighting. quick-union من غير وزن يقدر يبقى O(N) في أسوأ حالة، وده بيحصل بسهولة لو المدخلات مترتبة. الوزن سطرين بيحموا من الكارثة.

إيه قاعدة الـ weighted quick-union؟

كده الارتفاع مايزدش غير لما تتوحّد شجرتين نفس الحجم تقريبًا — وده بيحصل على الأكثر lg N مرة.

path halving بيعمل إيه وهو بيطلع للجذر؟

id[i] = id[id[i]] — سطر واحد، تأثير تراكمي رهيب.

لو عندك ملايين العناصر وملايين العمليات، أنهي نسخة تستخدم؟
