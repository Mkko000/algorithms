طيب، عرفنا إن في خوارزميات أسرع من خوارزميات. بس إزاي نقيس؟ نقول «دي سريعة» مش علم. سادجوك في الفصل التاني بيعلّمنا نتكلم بدقة من غير ما نغرق في حسابات تقيلة.

هدف الدرس: تفهم Big-Oh و Θ و Ω بالعامية، تحسّ الفرق بين N و N log N و N² برقم، وتعرف إن أسوأ حالة ومتوسط الحالة قصص مختلفة.

العدّ قبل الساعة

بدل ما نقول «أخد 3 مللي على جهازي»، نعدّ العمليات الأساسية: مقارنات، تبادلات، لمسات مصفوفة. العدد ده دالة في حجم المدخل N. الدالة دي هي اللي بنقارن بيها.

Big-Oh من غير رعب

قول T(N) = O(f(N)) معناه: من نقطة معيّنة وطالع، T(N) ≤ c · f(N) لثابت c. يعني T «مابتعدّيش» رتبة f. مش بيقول إنهم قد بعض بالظبط — بيقول سقف.

  • O = سقف (upper bound)
  • Ω = أرضية (lower bound)
  • Θ = الاتنين: الرتبة المضبوطة

عمليًا بنقول «O(N log N)» ونقصد الرتبة المعتادة. المهم: الثوابت والأجزاء الصغيرة بتختفي. 3N² + 100N + 50 هي O(N²).

حسّ الرقمعلى جهاز بيعمل مليار عملية في الثانية تقريبًا: N=10⁶، خوارزمية N² محتاجة ~10¹² عملية = ألف ثانية. نفس N بخوارزمية N log N ≈ 2·10⁷ عملية = 0.02 ثانية. ده مش فرق نظري — ده فرق «يستنى قهوة» و«هلّص قبل ما تغلي».

بحث تتابعي ضد بحث ثنائي

على مصفوفة مرتّبة، البحث التتابعي O(N). الثنائي: كل مرة نصغّر المجال للنص → O(log N). سادجوك بيورّي البرنامجين جنب بعض عشان الرقم يضرب في وشك.

int binary_search(int a[], int l, int r, int v) {
    while (r >= l) {
        int m = l + (r - l) / 2;
        if (v == a[m]) return m;
        if (v <  a[m]) r = m - 1;
        else           l = m + 1;
    }
    return -1;
}
خلي بالك(l+r)/2 ممكن يعمل overflow لو l و r كبار. المضمون أكتر: l + (r-l)/2. تفصيلة صغيرة، في الأنظمة الكبيرة بتكسر شغل.

أنواع التكلفة

أسوأ حالة = العدو اللي بنصمّم ضده (quicksort العادي على مصفوفة مرتّبة = N²). متوسط الحالة = على مدخل عشوائي. أفضل حالة نادرًا يهمّ — إلا لو بيحصل كتير (insertion sort على بيانات شبه مرتّبة).

كمان في تكلفة مستهلكة amortized: عملية واحدة غالية، بس متوسطها على تسلسل طويل رخيص (زي path compression).

إيه الفرق بين O و Θ؟

كل Θ(f) هي O(f)، العكس مش صحيح. N = O(N²) صح، بس N مش Θ(N²).

ليه ما نعتمدش على ساعة الإيقاف وحدها؟

القياس التجريبي مهم للتأكيد، بس التحليل الرياضي بيورّي السلوك لما N يكبر بعيد عن جهازك.
