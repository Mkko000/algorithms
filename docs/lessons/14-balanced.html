الـ BST العادي مقامر. عشان ننام بالليل محتاجين ضمان: ارتفاع O(log N) مهما كان ترتيب الإدخال. الفصل 13 بيعرض عائلة حلول: randomized، splay، red-black، skip lists.

هدف الدرس: تفهم فكرة التوازن، تركز على Red-Black (تمثيل 2-3-4)، وتأخذ لمحة عن Randomized BST.

Randomized BST

عند الإدخال: باحتمال 1/(N+1) ادخل عند الجذر (root insertion)، وإلا انزل عادي. النتيجة: لكل مفتاح نفس فرصة يكون جذر أي شجرة فرعية — المتوقع متوازن، من غير ألوان ولا حالات.

Red-Black = 2-3-4 Tree متنكّرة

سادجوك بيشرحها عبر أشجار 2-3-4: عقد تقدر تمسك 1 أو 2 أو 3 مفاتيح. الإدخال بيكسر الـ 4-nodes في الطريق لتحت، فيلاقي مكانًا دايمًا. الترجمة لشجرة ثنائية: رابط أحمر = «المفتاحين دول في نفس عقدة 2-3-4».

  • مفيش مسارين أحمرين ورا بعض
  • كل طريق من الجذر لورقة فيه نفس عدد السود
/* split 4-nodes on the way down */
if (h->l->red && h->r->red) {
    h->red = 1; h->l->red = 0; h->r->red = 0;
}
/* ... insert recursively, rotate on the way up ... */
