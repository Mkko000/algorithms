البحث العادي بيقارن مفاتيح كاملة. Radix search بيقارن خانة خانة (بت أو حرف). الهيكل الطبيعي لكده: الـ Trie.

هدف الدرس: تفهم الـ binary trie، والـ TST كحل وسط عملي للنصوص.

Binary Trie

كل مستوى = بت من المفتاح. شمال = 0، يمين = 1. الأوراق فيها المفاتيح. البحث: امشي حسب البتات لحد ورقة، وقارن.

حلو لما المفاتيح قصيرة وعلى أبجدية صغيرة (بتات). لو كل حرف = 256 فرع، العقد الداخلية بتاكل ذاكرة بلا رحمة.

Ternary Search Trie (TST)

حل سادجوك الأنيق: كل عقدة تمسك حرف واحد وتلات روابط — أصغر / يكمل / أكبر. زي BST على الحرف الحالي، وزي trie لما تكمل للخانة التالية.

/* فكرة الإدخال */
if (ch < h->c)      h->l = insertR(h->l, s, val, d);
else if (ch > h->c) h->r = insertR(h->r, s, val, d);
else if (d < len-1) h->m = insertR(h->m, s, val, d+1);
else                h->val = val;
امتى TST؟قاموس نصوص، إكمال تلقائي، بحث بادئة. أسرع عمليًا من BST على النصوص الطويلة (لأن المقارنات بتوقف عند أول اختلاف مبكرًا ومش بتتعاد من الأول كل مرة)، وأخف من R-way trie.
