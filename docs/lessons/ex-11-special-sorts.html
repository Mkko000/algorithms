تمارين محلولة · الفصل 11 (Special-Purpose Sorting Methods) · تمارين 11.1–11.48

الفصل الـ 11 فيه عالمين: الأول sorting networks (Batcher)، وده ترتيب «من غير if»: سلسلة compare-exchange ثابتة مهما كانت الداتا. والتاني external sorting، والداتا هنا مش هتكفّي الذاكرة والتكلفة الحقيقية هي عدد الـ passes على الديسك. التمارين بتمشي في الاتنين، وفيها مفاجأة صغيرة: Program 11.2 مابيشتغلش على مثال التمرين 11.8 زي ما هو.

هدف الدرس: تتتبّع shuffle/unshuffle وBatcher merge بالإيد، وتثبت إن network بيرتّب باستعمال مبدأ 0-1، وتعدّ الـ comparators والـ parallel steps، وتحسب عدد الـ passes والـ runs في الـ external sort.
مبدأ 0-1 هو سلاحكعشان تثبت إن network فيه N خط بيرتّب، مش محتاج تجرّب الـ N! permutation. كفاية الـ 2N input اللي كلهم 0 و1 (Property 11.1). ولـ N = 6 ده 64 بدل 720، ولـ N = 16 ده 65536 بدل 20 تريليون.

بنفكّر إزايnetwork الـ sort لـ 2n = اتنين sort لـ 2n−1 + merge. والـ merge M(n) = 2M(n−1) + (2n−1 − 1)، وحلّها M(n) = (n−1)2n−1 + 1، ودي بالظبط 1، 3، 9، 25، 65. يعني الشكل اللي في Figure 11.7 بيعدّ الـ merge networks. والـ sort S(n) = 2S(n−1) + M(n)، وحلّها S(n) = (n² − n + 4)·2n−2 − 1.
