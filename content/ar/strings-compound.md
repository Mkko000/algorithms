## 3.6 النصوص

في C النص = مصفوفة `char` بتنتهي بـ `'\0'`. مفيش طول متخزّن؛ عشان تعرف الطول لازم تمشي لحد الصفر. Table 3.2 في الكتاب بتكتب دوال المكتبة بطريقتين، وده تمرين يستاهل:

```c
/* بالفهارس */                         /* بالمؤشرات */
for (i = 0; a[i] != 0; i++) ;            b = a; while (*b++) ;
return i;               /* strlen */     return b - a - 1;

for (i = 0; (a[i] = b[i]) != 0; i++) ;   while (*a++ = *b++) ;   /* strcpy */

for (i = 0; a[i] == b[i]; i++)           /* strcmp */
  if (a[i] == 0) return 0;
return a[i] - b[i];
```

:::oops فخ strlen
`for (i = 0; i < strlen(a); i++)` شكلها بريء، بس `strlen` بيلف على النص كله **في كل لفة**. اللوب الخطي بقى N². على نص مليون حرف ده الفرق بين ملي ثانية ودقايق. احسب الطول مرة واحدة قبل اللوب، أو امشي لحد `'\0'`.
:::

### ترتيب نصوص (Program 3.17)

الخدعة الذكية: اقرا كل الكلمات في **بافر واحد كبير**، واحتفظ بمصفوفة **مؤشرات** لأول كل كلمة، ورتّب المؤشرات بـ `qsort` ودالة مقارنة بتنادي `strcmp`. النصوص نفسها ماتتحرّكش أبدًا — بنحرّك مؤشرات حجمها 8 بايت. دي نفس فكرة «pointer sort» اللي هنعمّقها في الدرس 16.

```c listing="Program 3.17"
int compare(const void *i, const void *j)
  { return strcmp(*(char **)i, *(char **)j); }
...
qsort(a, N, sizeof(char *), compare);
```

## 3.7 هياكل مركّبة

### مصفوفة ثنائية الأبعاد ديناميكية (Program 3.16)

عايز مصفوفة r×c حجمها يتحدد وقت التشغيل؟ احجز مصفوفة مؤشرات r، وكل مؤشر يشاور على صف من c عنصر. وبعدها `t[i][j]` تشتغل عادي.

```c listing="Program 3.16"
int **malloc2d(int r, int c)
  { int i; int **t = malloc(r * sizeof(int *));
    for (i = 0; i < r; i++) t[i] = malloc(c * sizeof(int));
    return t; }
```

### مصفوفة ثنائية من القوائم — أقرب النقط تاني (Program 3.20)

رجعنا لمشكلة «كام زوج نقط المسافة بينهم أقل من d». الفكرة: قسّم المربع لشبكة G×G خلايا، كل خلية ضلعها d، وكل خلية فيها **قايمة** النقط اللي وقعت فيها. أي نقطتين أقرب من d لازم يكونوا في نفس الخلية أو خلية جنبها. فكل نقطة جديدة بتتقارن بس بالنقط في 9 خلايا.

```
$ ./point_closest 20000 0.005
  brute force: 15808 pairs closer than d, 199990000 distance computations
  grid lists : 15808 pairs closer than d,     44772 distance computations
```

نفس الإجابة، أقل **4000 مرة** في الحسابات. ودي مش خوارزمية جديدة — دي هيكل بيانات أذكى. الحيلة الصغيرة: نحجز صف وعمود زيادة على الحواف عشان مانكتبش شروط حدود.
