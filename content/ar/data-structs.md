## 3.1 اللبنات الأساسية

**Definition 3.1:** نوع البيانات = **مجموعة قيم + مجموعة عمليات على القيم دي**. سادجوك بيقول جملة مهمة: العمليات مرتبطة بالنوع، مش العكس. `int` مش بس «رقم صحيح»، هو كمان «+ و − و \* و / و % بالطريقة دي» (القسمة بتقطع الكسر!).

الكتاب بيستخدم `typedef` عشان البرنامج مايتربطش بنوع معيّن. Program 3.2 بيحسب متوسط وانحراف معياري لأرقام عشوائية، ولو غيّرت `typedef int Number;` لـ `float` البرنامج يشتغل على أنواع تانية من غير ما تلمس الباقي. دي بذرة فكرة الـ ADT (الدرس 8).

### نوع جديد: point (Programs 3.3–3.4)

نجمع حاجتين في `struct`، ونكتب الدوال اللي بتشتغل عليه في ملف لوحده:

```c listing="Program 3.3"
/* Point.h — الواجهة (Program 3.3) */
typedef struct { float x; float y; } point;
float distance(point a, point b);

/* Point.c — التنفيذ (Program 3.4) */
#include <math.h>
float distance(point a, point b)
  { float dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx*dx + dy*dy); }
```

ليه نفصلهم؟ عشان أي برنامج يستخدم النقط يعمل `#include "Point.h"` ومالوش دعوة بالتفاصيل. ده أول «عقد» بين واجهة وتنفيذ في الكتاب.

## 3.2 المصفوفة: وصول عشوائي في خطوة

المصفوفة = خانات ورا بعض في الذاكرة. `a[i]` بيتحسب كـ «عنوان البداية + i × حجم الخانة»، فبيجي في O(1) مهما كانت i. ده أهم سبب إن المصفوفات في كل حتة: الكاش بيحبها، والكود بسيط. الوحش: الحجم ثابت غالبًا، والإدراج في النص بيزق كل اللي بعده.

### مثال 1: غربال إيراتوستينس (Program 3.5)

عايز كل الأعداد الأولية لحد N؟ مصفوفة flags: `a[i]=1` يعني «لسه محتمل يكون أولي». لكل i أولي، اشطب مضاعفاته. المصفوفة هنا مش «بيانات» — هي **مجموعة** (set) متمثّلة بأعلام، والفهرس هو العنصر. التكلفة ≈ N ln ln N، يعني خطية تقريبًا.

```c listing="Program 3.5"
for (i = 2; i < N; i++) a[i] = 1;
for (i = 2; i < N; i++)
  if (a[i])
    for (j = i; i*j < N; j++) a[i*j] = 0;
```

### مثال 2: الحجم وقت التشغيل (Program 3.6)

بدل `#define N 10000` نقرأ N من المستخدم ونطلب الذاكرة بـ `malloc`. وافحص الرجوع! لو `NULL` يبقى الذاكرة خلصت.

```c listing="Program 3.6"
int *a = malloc(N * sizeof(int));
if (a == NULL) { printf("Insufficient memory.\n"); return; }
```

### مثال 3: المصفوفة كعدّادات — رمي العملة (Program 3.7)

ارمي عملة N مرة، كرّر التجربة M مرة، وعدّ في `f[i]` كام تجربة طلع فيها i «صورة». ارسم نجوم: هيطلعلك **منحنى الجرس** (التوزيع الطبيعي كتقريب لذات الحدّين) من مصفوفة عدّادات بس. الفهرس هنا = قيمة، والخانة = تكرارها — نفس الفكرة اللي هنرجعلها في key-indexed counting (الدرس 16).

### مثال 4: مصفوفة structs — أقرب النقط (Program 3.8)

N نقطة عشوائية في المربع الوحدة: كام زوج المسافة بينهم أقل من d؟ الحل المباشر: كل زوج (≈ N²/2 مسافة). شغّال بس مايستحملش N كبير. في الدرس 7 هنشوف Program 3.20 بيحلّها بشبكة قوائم ويعمل **أقل بألف مرة** من الحسابات بنفس النتيجة.

```c
for (i = 0; i < N; i++)
  for (j = i+1; j < N; j++)
    if (distance(a[i], a[j]) < d) cnt++;
```
