## 5.4 أنواع الشجر

الكتاب بيمشي من الأكثر تحديدًا للأعمّ:

* **Definition 5.1 — شجرة ثنائية:** إما عقدة خارجية (external node، فاضية)، أو عقدة داخلية متوصّلة بزوج شجر ثنائية مرتّب (شمال ويمين).
* **Definition 5.2 — شجرة M-ary:** نفس الفكرة بس العقدة الداخلية ليها M ابن مرتبين.
* **Definition 5.3 — شجرة مرتّبة (ordered tree):** عقدة (الجذر) متوصّلة بـ**متتابعة** شجر منفصلة (اسمها forest). عدد الأبناء مش ثابت، ومفيش «عقد خارجية».
* **Definition 5.4 — شجرة جذرية غير مرتبة:** الجذر متوصّل بـ**مجموعة** شجر — ترتيب الأبناء مش مهم. دي شجر الـ union-find في الدرس 02.
* **Definition 5.5 — جراف:** عقد وأضلاع بتوصّل أزواج عقد مختلفة. و**الشجرة الحرة (free tree)** = جراف من غير جذر، بأي شرط من الأربعة المتكافئين: N−1 ضلع ومفيش دورات · N−1 ضلع ومتصل · مسار بسيط واحد بالظبط بين أي عقدتين · متصل ولو شلت أي ضلع يتقطع.

مصطلحات لازم تبقى طبيعية عندك: parent / child / sibling، leaf (عقدة ملهاش أبناء)، **level** العقدة = عمقها (الجذر 0)، **height** الشجرة = أكبر level، **path length** = مجموع levels العقد.

### Property 5.4: كل forest = شجرة ثنائية

في تطابق واحد لواحد بين الشجر الثنائية والـ forests المرتبة: خلّي الرابط الشمال لكل عقدة يشاور على **أول ابن**، والرابط اليمين يشاور على **الأخ اللي بعده** («left-child, right-sibling»). يعني أي شجرة عدد أبنائها متغير تقدر تخزّنها بعقد فيها مؤشرين بس.

## 5.6 المشي في الشجرة

Program 5.14: ريكيرشن بثلاث سطور، والفرق بين الأنواع هو **إمتى تزور العقدة**:

```c listing="Program 5.14"
void traverse(link h, void (*visit)(link))
  { if (h == NULL) return;
    (*visit)(h);              /* preorder  : قبل الأبناء */
    traverse(h->l, visit);
    traverse(h->r, visit); }  /* inorder: بينهم · postorder: بعدهم */
```

```
preorder:    E D B A C H F G I
inorder:     A B C D E F G H I      ← BST: الـ inorder مرتّب
postorder:   A C B D G F I H E
```

::figure traversal

### بـ stack صريح (Program 5.15) وبـ queue (Program 5.16)

الـ preorder من غير ريكيرشن: push الجذر؛ وطول ما الـ stack مش فاضي: pop وزور، وpush **اليمين الأول** وبعدين الشمال (عشان الشمال يطلع الأول). ودي نفس النتيجة بالظبط: `preorder_nr: E D B A C H F G I`.

والمفاجأة: **بدّل الـ stack بـ queue** في نفس الكود، تطلع level-order — مستوى مستوى من فوق لتحت. نفس الفكرة دي هي الفرق بين DFS وBFS في الدرس الجاي.

```c
void traverse(link h, void (*visit)(link))
  { QUEUEput(h);
    while (!QUEUEempty())
      { (*visit)(h = QUEUEget());
        if (h->l != NULL) QUEUEput(h->l);
        if (h->r != NULL) QUEUEput(h->r); } }
```

## 5.7 خوارزميات ريكيرسف على الشجر الثنائية

### العدّ والارتفاع (Program 5.17)

```c listing="Program 5.17"
int count(link h)
  { if (h == NULL) return 0;
    return count(h->l) + count(h->r) + 1; }
int height(link h)
  { int u, v;
    if (h == NULL) return -1;
    u = height(h->l); v = height(h->r);
    if (u > v) return u+1; else return v+1; }
```

لاحظ `height(NULL) = -1` عشان شجرة بعقدة واحدة ارتفاعها 0.

### طباعة سريعة (Program 5.18)

inorder معكوس (يمين، جذر، شمال) مع مسافات على قد العمق = الشجرة مطبوعة مقلوبة 90 درجة. الـ `*` هي العقد الخارجية. أداة debugging عظيمة لأي شجرة في الكتاب.

### شجرة البطولة (Program 5.19)

divide-and-conquer بتاع max (الدرس 11)، بس بدل ما نرمي النتايج الوسيطة، **نبني منها شجرة**: كل عقدة = أكبر قيمة في ابنيها. الجذر هو الفايز. ودي تمهيد للـ heap والـ priority queues.

```
tournament on {1 7 3 9 4 2 8 5}: winner=9
level order: 9 9 8 7 9 4 8 1 7 3 9 4 2 8 5
```

### شجرة التحليل (Program 5.20)

نفس تقييم prefix بتاع الدرس 11، بس بدل ما نحسب، نبني شجرة: العملية جذر، والمعاملين ابنين. الـ inorder عليها = التعبير infix، والـ postorder = postfix. المترجمات كلها بتعمل كده.
